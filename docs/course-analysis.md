### หน่วยที่ 1 หลักการเบื้องต้นของโครงสร้างข้อมูลและอัลกอริทึม ✅ (เปิดให้เรียนแล้ว)
1. ข้อมูล สารสนเทศ และลำดับชั้นของข้อมูล — *แอนิเมชัน 1.1-ก, 1.1-ข*
2. ชนิดข้อมูลและการจัดเก็บในหน่วยความจำ — *แอนิเมชัน 1.2-ก, 1.2-ข*
3. ความหมายและประเภทของโครงสร้างข้อมูล (Linear / Non-linear) — *แอนิเมชัน 1.3*
4. ข้อมูลแบบนามธรรม (Abstract Data Type) — *กิจกรรม 1.4*
5. อัลกอริทึม รหัสเทียม และผังงาน — *แอนิเมชัน 1.5*
6. การวิเคราะห์ประสิทธิภาพอัลกอริทึม (Big-O) — *แอนิเมชัน 1.6-ก, 1.6-ข, กราฟ 1.6-ค*
- ใบงาน 1.1–1.4 ในชั่วโมงปฏิบัติ, ใบงาน 1.5 เป็นงานเสริม และแบบทดสอบ 12 ข้อ

### หน่วยที่ 2 อาร์เรย์และเรคคอร์ด
1. ADT ของลิสต์ และการสร้างด้วยอาร์เรย์
2. อาร์เรย์ 1 มิติ: การประกาศ การเข้าถึง การคำนวณตำแหน่งในหน่วยความจำ
3. อาร์เรย์ 2 มิติ: Row-major และ Column-major
4. การแทรก ลบ และค้นหาในอาร์เรย์ พร้อมความซับซ้อน
5. เรคคอร์ด/โครงสร้าง (struct, class, dict)

### หน่วยที่ 3 ลิงค์ลิสต์
1. แนวคิดโหนดและตัวชี้ (Node & Pointer)
2. ลิงค์ลิสต์ทางเดียว: การแทรก ลบ และท่องลิสต์
3. ลิงค์ลิสต์สองทาง (Doubly Linked List)
4. ลิงค์ลิสต์วงกลม (Circular Linked List)
5. เปรียบเทียบอาร์เรย์กับลิงค์ลิสต์

### หน่วยที่ 4 สแตกและคิว
1. ADT ของสแตก (LIFO) และการสร้างด้วยอาร์เรย์/ลิงค์ลิสต์
2. การประยุกต์สแตก: ตรวจวงเล็บ แปลง Infix เป็น Postfix และคำนวณ Postfix
3. การเรียกซ้ำ (Recursion) และ Call Stack
4. ADT ของคิว (FIFO) และคิววงกลม (Circular Queue)
5. คิวลำดับความสำคัญ (Priority Queue) และคิวสองหัว (Deque)
6. การประยุกต์คิว: คิวงานพิมพ์ การจำลองคิวบริการ

### หน่วยที่ 5 ทรี
1. ศัพท์พื้นฐาน: root, leaf, level, height, degree
2. ไบนารีทรีและการแทนในหน่วยความจำ
3. การท่องทรี: Preorder, Inorder, Postorder, Level-order
4. ไบนารีเสิร์ชทรี (BST): เพิ่ม ค้นหา ลบ
5. ทรีนิพจน์ (Expression Tree) และฮีป (Heap) เบื้องต้น

### หน่วยที่ 6 กราฟ
1. ศัพท์พื้นฐานและชนิดของกราฟ (มีทิศทาง ไม่มีทิศทาง มีน้ำหนัก)
2. การแทนกราฟ: Adjacency Matrix / Adjacency List
3. การค้นหาแนวกว้าง (BFS)
4. การค้นหาแนวลึก (DFS)
5. เส้นทางสั้นที่สุด (Dijkstra) และต้นไม้แผ่ทั่วที่น้อยที่สุด (MST) เบื้องต้น

### หน่วยที่ 7 อัลกอริทึมการจัดเรียงข้อมูล
1. แนวคิดการจัดเรียง: stable, in-place
2. Bubble Sort และ Selection Sort
3. Insertion Sort
4. Merge Sort
5. Quick Sort
6. เปรียบเทียบประสิทธิภาพการจัดเรียง

### หน่วยที่ 8 อัลกอริทึมการค้นหาข้อมูล
1. การค้นหาแบบลำดับ (Sequential Search)
2. การค้นหาแบบทวิภาค (Binary Search)
3. ตารางแฮชและฟังก์ชันแฮช (Hashing)
4. การแก้การชนกัน: Chaining, Open Addressing
5. เปรียบเทียบวิธีค้นหา

### หน่วยที่ 9 ต้นไม้ตัดสินใจ
1. แนวคิดและองค์ประกอบของต้นไม้ตัดสินใจ
2. ใช้ต้นไม้ตัดสินใจและตารางการตัดสินใจวิเคราะห์ความต้องการ
3. สร้างต้นไม้ตัดสินใจจากข้อมูล (Entropy, Information Gain)
4. แปลงต้นไม้ตัดสินใจเป็นโปรแกรม

### หน่วยที่ 10 บูรณาการการพัฒนาโปรแกรม
1. วิเคราะห์ปัญหาและเลือกโครงสร้างข้อมูลที่เหมาะสม
2. ออกแบบอัลกอริทึม (รหัสเทียม/ผังงาน)
3. พัฒนาโปรแกรมเป็นทีม ทดสอบ และวัดประสิทธิภาพ
4. นำเสนอผลงาน

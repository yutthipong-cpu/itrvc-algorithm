      1.1

      ข้อมูล สารสนเทศ และลำดับชั้นของข้อมูลData, Information & Data Hierarchy

      คอมพิวเตอร์รับข้อมูลเข้ามา ประมวลผล แล้วส่งออกเป็นสารสนเทศ งานของโปรแกรมเมอร์คือออกแบบว่าจะเก็บข้อมูลอย่างไร (โครงสร้างข้อมูล) และประมวลผลอย่างไร (อัลกอริทึม) ให้ได้สารสนเทศที่ถูกต้องและรวดเร็ว

      ข้อมูล Data
      ข้อเท็จจริงดิบที่ยังไม่ผ่านการประมวลผล เช่น ตัวเลข ข้อความ ภาพ เสียง
      การประมวลผล Processing
      การคำนวณ เรียงลำดับ เปรียบเทียบ สรุปผล เพื่อให้ข้อมูลมีความหมาย
      สารสนเทศ Information
      ผลลัพธ์จากการประมวลผลที่มีความหมาย ถูกต้อง ทันเวลา และนำไปใช้ตัดสินใจได้

      ลำดับชั้นของข้อมูล (Data Hierarchy)

      ข้อมูลในคอมพิวเตอร์ประกอบขึ้นจากหน่วยเล็กไปหาใหญ่ 6 ระดับ ทุกระดับสร้างจากระดับที่เล็กกว่า จนถึงฐานข้อมูลที่เก็บข้อมูลทั้งระบบ

      จำไว้

      Niklaus Wirth ผู้สร้างภาษา Pascal ตั้งชื่อหนังสือว่า Algorithms + Data Structures = Programs (1976) โปรแกรมที่ดีจึงต้องเลือกโครงสร้างข้อมูลและอัลกอริทึมให้เหมาะกันเสมอ

      สรุปหัวข้อ 1.1

      • ข้อมูล → ประมวลผล → สารสนเทศ
      • บิต → ไบต์ (8 บิต) → ฟิลด์ → เรคคอร์ด → ไฟล์ → ฐานข้อมูล
      1.2

      ชนิดข้อมูลและการจัดเก็บในหน่วยความจำData Types & Memory

      หน่วยความจำหลัก (RAM) แบ่งเป็นช่อง ช่องละ 1 ไบต์ แต่ละช่องมีเลขที่อยู่ (address) ไม่ซ้ำกัน เมื่อประกาศตัวแปร คอมพิวเตอร์จะจองช่องว่างตามขนาดของชนิดข้อมูล (Data Type) ชนิดข้อมูลจึงกำหนด 3 อย่าง: ใช้พื้นที่กี่ไบต์ เก็บค่าได้ในช่วงใด และทำการดำเนินการอะไรได้บ้าง

      ชนิดข้อมูล (C/C++)ตัวอย่างขนาดช่วงค่าโดยประมาณใน Python
      char'A'1 ไบต์−128 ถึง 127 (รหัสอักขระ)str
      int174 ไบต์−2,147,483,648 ถึง 2,147,483,647int (ขยายขนาดได้ไม่จำกัด)
      float3.254 ไบต์ทศนิยมแม่นยำราว 7 หลัก—
      double3.141592658 ไบต์ทศนิยมแม่นยำราว 15 หลักfloat
      booltrue1 ไบต์true / falsebool

      ภาพนี้ย่อให้เข้าใจง่าย: ในเครื่องจริงตัวแปรอาจถูกจัดให้ตรงขอบ (alignment) และเรียงไบต์แบบ little-endian ส่วนใน Python ทุกค่าเป็นอ็อบเจกต์ จึงใช้พื้นที่มากกว่านี้ (ลองใช้ sys.getsizeof() ในใบงาน 1.2) แต่หลักการจองพื้นที่ตามชนิดข้อมูลยังเหมือนเดิม

      ทำไมต้องเป็นเลขฐานสอง

      วงจรอิเล็กทรอนิกส์แยกสถานะได้ชัดเจน 2 แบบ คือมีไฟกับไม่มีไฟ ค่าทุกอย่างในหน่วยความจำจึงเป็นเลขฐานสอง การแปลงเลขฐานสิบเป็นฐานสองทำได้โดยหารด้วย 2 ซ้ำ ๆ แล้วอ่านเศษจากล่างขึ้นบน

      สรุปหัวข้อ 1.2

      • หน่วยความจำ 1 ช่อง = 1 ไบต์ มีเลขที่อยู่ประจำช่อง
      • ชนิดข้อมูลกำหนดขนาด ช่วงค่า และการดำเนินการที่ทำได้
      • ฐานสิบ → ฐานสอง: หารด้วย 2 ซ้ำ อ่านเศษจากล่างขึ้นบน

      1.4

      ข้อมูลแบบนามธรรมAbstract Data Type (ADT)

      ข้อมูลแบบนามธรรม (ADT) คือการนิยามชนิดข้อมูลด้วยสิ่งที่มันทำได้ (ข้อมูล + ชุดการดำเนินการ) โดยไม่ระบุวิธีสร้างภายใน เหมือนรีโมตทีวีที่เรากดปุ่มเพิ่มเสียงได้โดยไม่ต้องรู้ว่าวงจรข้างในทำงานอย่างไร

      ADT แบ่งเป็น 2 ส่วน: ข้อกำหนด (Specification) บอกว่ามีการดำเนินการอะไรและให้ผลอย่างไร และการสร้าง (Implementation) คือโค้ดจริงที่ทำงานตามข้อกำหนด ADT หนึ่งตัวจึงสร้างได้หลายวิธี

      ADT: Stackความหมาย
      push(x)เพิ่ม x ไว้บนสุด
      pop()นำค่าบนสุดออกและคืนค่านั้น (ถ้าว่าง = Underflow)
      peek()ดูค่าบนสุดโดยไม่นำออก
      isEmpty()ตรวจว่าว่างหรือไม่
      size()จำนวนข้อมูลในสแตก

      สรุปหัวข้อ 1.4

      • ADT = ข้อมูล + การดำเนินการ โดยซ่อนวิธีสร้างไว้ (Abstraction / Encapsulation)
      • เปลี่ยนวิธีสร้างภายในได้โดยไม่กระทบโค้ดที่เรียกใช้
      • วิธีสร้างแต่ละแบบมีข้อดีข้อเสีย เช่น อาร์เรย์มีขนาดจำกัด ลิงค์ลิสต์ขยายได้แต่ใช้พื้นที่เก็บตัวชี้เพิ่ม
      1.5

      อัลกอริทึม รหัสเทียม และผังงานAlgorithms, Pseudocode & Flowcharts

      อัลกอริทึม (Algorithm) คือลำดับขั้นตอนที่ชัดเจนและมีจำนวนจำกัด สำหรับแก้ปัญหาหนึ่ง ๆ ชื่อนี้มาจาก al-Khwārizmī นักคณิตศาสตร์ชาวเปอร์เซียในศตวรรษที่ 9 อัลกอริทึมที่ดีต้องมีคุณสมบัติ 5 ข้อ

      ข้อมูลเข้า Input
      รับข้อมูลเข้าตั้งแต่ 0 ค่าขึ้นไป
      ผลลัพธ์ Output
      ให้ผลลัพธ์อย่างน้อย 1 ค่า
      ความชัดเจน Definiteness
      ทุกขั้นตอนชัดเจน ตีความได้แบบเดียว
      ความจำกัด Finiteness
      ต้องจบการทำงานภายในจำนวนขั้นตอนที่จำกัด
      ทำได้จริง Effectiveness
      แต่ละขั้นตอนทำได้จริงด้วยการคำนวณพื้นฐาน

      วิธีเขียนอัลกอริทึม 3 แบบ

      • ภาษาธรรมชาติ: เขียนเป็นข้อความ เช่น "1. ให้ตัวแรกเป็นค่ามากสุด 2. ไล่ดูตัวถัดไปทีละตัว ถ้ามากกว่าให้จำค่านั้นแทน 3. แสดงค่าที่จำไว้"
      • รหัสเทียม (Pseudocode): เขียนคล้ายโค้ดแต่ไม่ยึดไวยากรณ์ภาษาใด แปลงเป็นโปรแกรมได้ง่าย
      • ผังงาน (Flowchart): ใช้สัญลักษณ์มาตรฐานและลูกศรแสดงลำดับการทำงาน
      เริ่มต้น / จบTerminal
      ประมวลผลProcess
      รับ / แสดงผลInput / Output
      ตัดสินใจDecision
      ทิศทางFlow line

      ตัวอย่างต่อไปนี้หาค่ามากที่สุดในอาร์เรย์ และใช้โครงสร้างควบคุมครบทั้ง 3 แบบ: ตามลำดับ (กำหนดค่าเริ่มต้น) เลือกทำ (ถ้า A[i] > max) และทำซ้ำ (ขณะที่ i < n) ดูให้ครบทั้งอาร์เรย์ ตัวแปร รหัสเทียม และผังงานซึ่งเคลื่อนไปพร้อมกัน

      สรุปหัวข้อ 1.5

      การวิเคราะห์ประสิทธิภาพอัลกอริทึมAlgorithm Analysis & Big-O Notation

      ปัญหาเดียวกันแก้ได้หลายวิธี เราจึงต้องวัดว่าวิธีไหนดีกว่า การจับเวลาเป็นวินาทีไม่ยุติธรรม เพราะคอมพิวเตอร์แต่ละเครื่องเร็วไม่เท่ากัน จึงวัดเป็นจำนวนขั้นตอนพื้นฐานที่ต้องทำ เมื่อข้อมูลมีขนาด n

      ความซับซ้อนด้านเวลา Time Complexity
      จำนวนขั้นตอนที่อัลกอริทึมต้องทำ เทียบกับขนาดข้อมูล n
      ความซับซ้อนด้านพื้นที่ Space Complexity
      หน่วยความจำเพิ่มเติมที่อัลกอริทึมต้องใช้ เทียบกับขนาดข้อมูล n
      กรณีดีสุด / เฉลี่ย / แย่สุด Best / Avg / Worst
      Linear Search: เจอตัวแรก = 1 ครั้ง (ดีสุด) · อยู่ท้ายสุดหรือไม่มี = n ครั้ง (แย่สุด)

      สัญกรณ์บิ๊กโอ (Big-O)

      Big-O บอกอัตราการเติบโตของจำนวนขั้นตอนเมื่อ n ใหญ่มาก โดยมักดูกรณีแย่ที่สุด มีกฎย่อ 3 ข้อ

      1. ตัดค่าคงที่ทิ้ง: 2n + 5 → O(n)
      2. เก็บเฉพาะพจน์ที่โตเร็วที่สุด: n² + 3n + 1 → O(n²)
      3. ลูปต่อกันให้บวก ลูปซ้อนให้คูณ: ลูป n ตามด้วยลูป n = O(n) · ลูป n ซ้อนในลูป n = O(n × n) = O(n²)

      Binary Search ดูตัวกลาง ถ้าค่าที่หาน้อยกว่าก็ตัดครึ่งขวาทิ้ง ถ้ามากกว่าก็ตัดครึ่งซ้ายทิ้ง ข้อมูลจึงลดลงครึ่งหนึ่งทุกครั้ง แต่ใช้ได้กับข้อมูลที่เรียงลำดับแล้วเท่านั้น (ศึกษาละเอียดในหน่วยที่ 9)

      ถ้า n ใหญ่ขึ้นจริง ๆ ต่างกันแค่ไหน

      จำนวนขั้นตอน และเวลาโดยประมาณ (สมมติคอมพิวเตอร์ทำได้ 1 ล้านขั้นตอนต่อวินาที)

      Big-On = 10n = 100n = 1,000n = 1,000,000

      Big-O ที่พบบ่อย

      Big-Oชื่อเรียกตัวอย่างอัลกอริทึมเรียนในหน่วย
      O(1)คงที่เข้าถึง A[i], push/pop ของสแตก2, 4
      O(log n)ลอการิทึมBinary Search, ค้นหาใน BST ที่สมดุล6, 9
      O(n)เชิงเส้นLinear Search, หาค่าสูงสุด, ท่องลิงค์ลิสต์1, 3, 9
      O(n log n)n log nMerge Sort, Quick Sort (กรณีเฉลี่ย)8
      O(n²)กำลังสองBubble, Selection, Insertion Sort8
      O(2ⁿ)เอกซ์โพเนนเชียลลองทุกชุดคำตอบ, Fibonacci แบบเรียกซ้ำตรง ๆ4

      สรุปหัวข้อ 1.6

      • วัดประสิทธิภาพเป็นจำนวนขั้นตอนเทียบกับ n ไม่ใช่วินาที
      • Big-O ตัดค่าคงที่ เก็บพจน์ที่โตเร็วที่สุด ลูปซ้อนให้คูณ
      • เร็วไปช้า: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)

      class ArrayStack:
    def __init__(self):
        self._data = []
    def push(self, x):
        self._data.append(x)
    def pop(self):
        if self.is_empty():
            raise IndexError("Stack Underflow")
        return self._data.pop()
    def peek(self):
        return self._data[-1]
    def is_empty(self):
        return len(self._data) == 0
    def size(self):
        return len(self._data)


class Node:
    def __init__(self, value, next=None):
        self.value = value
        self.next = next


class LinkedStack:
    def __init__(self):
        self._head = None
        self._n = 0
    def push(self, x):
        self._head = Node(x, self._head)
        self._n += 1
    def pop(self):
        if self.is_empty():
            raise IndexError("Stack Underflow")
        v = self._head.value
        self._head = self._head.next
        self._n -= 1
        return v
    def peek(self):
        return self._head.value
    def is_empty(self):
        return self._head is None
    def size(self):
        return self._n


for s in (ArrayStack(), LinkedStack()):
    for x in (12, 7, 25):
        s.push(x)
    print(type(s).__name__, "pop:", s.pop(), "peek:", s.peek(), "size:", s.size())

      import time

def linear_search(A, x):
    for i, v in enumerate(A):
        if v == x:
            return i
    return -1

def binary_search(A, x):
    lo, hi = 0, len(A) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if A[mid] == x:
            return mid
        if A[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

for n in [1_000, 10_000, 100_000, 1_000_000]:
    A = list(range(n))
    x = n - 1                     # กรณีแย่ที่สุดของ linear search
    t0 = time.perf_counter(); linear_search(A, x)
    t1 = time.perf_counter(); binary_search(A, x)
    t2 = time.perf_counter()
    print(f"n={n:>9,}  linear={(t1 - t0) * 1000:9.3f} ms  binary={(t2 - t1) * 1000:8.4f} ms")

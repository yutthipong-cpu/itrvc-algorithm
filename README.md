# ITRVC Algorithm Lab

เว็บบทเรียนแบบเห็นภาพ รายวิชา **31900-0005 โครงสร้างข้อมูลและอัลกอริทึม** (1-4-3, หลักสูตร 2567)
ทุกอัลกอริทึมเป็นแอนิเมชันที่เล่น หยุด ย้อนกลับ หรือเลื่อนไปขั้นใดก็ได้ และมีคำอธิบายประจำทุกขั้น

## เนื้อหาตอนนี้

- **ภาพรวมรายวิชา:** จุดประสงค์ สมรรถนะ และคำอธิบายรายวิชา จับคู่กับหน่วยการเรียน 11 หน่วย พร้อมแผนการสอน 18 สัปดาห์
- **หน่วยที่ 1 หลักการเบื้องต้นของโครงสร้างข้อมูลและอัลกอริทึม:** 6 หัวข้อ แอนิเมชันและกิจกรรม 10 ชิ้น ใบงาน Python 5 ใบ และแบบทดสอบ 12 ข้อ

ผลการวิเคราะห์รายวิชาฉบับเต็มอยู่ที่ [`docs/course-analysis.md`](docs/course-analysis.md)

## เปิดใช้งาน

เป็นเว็บแบบ static ไม่ต้อง build ไม่ต้องติดตั้งอะไร

- เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที หรือ
- รันเซิร์ฟเวอร์ในเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000
- เผยแพร่ด้วย GitHub Pages: Settings → Pages → Deploy from a branch → เลือก branch และโฟลเดอร์ `/ (root)`

## โครงสร้างไฟล์

```
index.html            หน้าเว็บทั้งหมด (ภาพรวมรายวิชา + หน่วยที่ 1) สลับหน้าด้วย #hash
css/style.css         สี ตัวอักษร และหน้าตา รองรับโหมดสว่าง/มืด และหน้าจอมือถือ
js/core.js            Stepper (ตัวเล่นแอนิเมชันทีละขั้น), แบบทดสอบ, router
js/course-data.js     ข้อมูลรายวิชาและหน่วยการเรียน (แก้หัวข้อ/สัปดาห์ที่ไฟล์นี้)
js/home.js            สร้างหน้าภาพรวมรายวิชาจาก course-data.js
js/unit1.js           แอนิเมชันและแบบทดสอบของหน่วยที่ 1
docs/course-analysis.md  ผลการวิเคราะห์รายวิชา
```

## เพิ่มหน่วยใหม่

1. เพิ่ม `<main id="unit-2" class="view" hidden>` ใน `index.html` (คัดลอกโครงจากหน่วยที่ 1)
2. สร้าง `js/unit2.js` ใช้ `new DSA.Stepper(element, { build, render })`
   - `build()` คืนค่าอาร์เรย์ของเฟรม แต่ละเฟรมคือสถานะ ณ ขั้นนั้น และมี `caption` อธิบายขั้นนั้น
   - `render(frame)` วาดสถานะของเฟรมนั้นลงหน้าจอ
3. ตั้งค่า `ready: true` ให้หน่วยนั้นใน `js/course-data.js` แล้วเพิ่มลิงก์ใน `.topnav`
